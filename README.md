# Folder Camera Android App

Features:
- Create unlimited folders
- Open camera directly from a selected folder
- Capture photos
- Automatically save each photo into the selected folder
- Automatically print date & time on the photo
- Automatic timestamp filename
- Works offline
- No storage permission is required because photos are stored in the app's private external Photos directory

## Build
Open this folder in Android Studio (Ladybug or newer), allow Gradle sync, then Run.

Package: com.example.foldercamera
Minimum Android: 8.0 (API 26)
